# RaceHub desktop shell

This repository contains an unfinished desktop shell based on Electron React Boilerplate.
It does not contain the full telemetry client interface.

## Development

Install the dependencies with `npm install`.
Start the app with `npm start`.
Build a local package with `npm run package`.

## Upstream

Electron React Boilerplate uses Electron, React, React Router, and webpack.
Its MIT licence remains in [LICENSE](LICENSE).
See the [upstream documentation](https://electron-react-boilerplate.js.org/).

Upstream contributors listed in the original README are Amila Welihinda, John Tran, C. T. Lin, and Jhen-Jie Hong.
They are not listed as RaceHub maintainers.
